Telegram 配置指引

1. 在 Telegram 搜索并私聊 @BotFather，发送 /newbot 按提示创建机器人。

2. 复制生成的 HTTP API Token 粘贴至左侧配置表单并保存。

3. 点击「生成新绑定链接」生成安全配对，或在下方手动添加允许访问的 Telegram User ID。

Discord 配置指引

1. 访问 Discord Developer Portal 创建应用。

2. 在 Bot 页面创建机器人并重置复制 Token；务必勾选开启 Message Content Intent 权限特权！

3. 保存后点击「邀请 Bot 到服务器」授权加入您的 Discord 服务器或频道。
